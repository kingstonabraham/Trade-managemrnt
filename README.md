# Trade Management Android Application

Professional trading journal, risk management, and discipline tracking app built with Kotlin and Jetpack Compose.

---

## 📱 Download & Install APK

The compiled Android application package (APK) is available directly in this repository:

- **Direct Repository File**: [`apk/TradeManagement.apk`](apk/TradeManagement.apk)
- **Size**: ~22 MB
- **Architecture**: Universal Android (API 26+)

### How to Install on Your Android Phone:
1. Download `apk/TradeManagement.apk` to your Android device or push this repository to GitHub.
2. In GitHub, go to the repository and click on **`apk/TradeManagement.apk`** -> **Download raw file**.
3. On your phone, open the downloaded APK file.
4. If prompted, allow **"Install unknown apps"** for your browser or file manager.
5. Tap **Install** and launch **Trade Management**!

## 🌟 Key Features

1. **Trade Logging & Real-time Calculations**:
   - Log trades for **Indian Stocks**, **US Stocks**, **Forex**, **Crypto**, and **Commodities**.
   - **Leverage Slider (1x to 100x)**: Accurately calculates both **Margin Required (With Leverage)** and **Total Position Exposure (Without Leverage)**.
   - P&L, Return %, Stop Loss, Target, Brokerage, and Taxes tracking.

2. **Market & Asset Filtering**:
   - Filter trades and performance metrics across **All**, **Indian Stocks**, **US Stocks**, and **Forex**.
   - Dedicated time views: **Day**, **Week**, and **Month**.

3. **Trading Discipline & Carry-Forward Tasks**:
   - Add daily routine and psychology tasks.
   - **Swipe Right** to mark task as **Completed**.
   - **Swipe Left** to **Delete** task.
   - **Automatic Carry-Forward**: Any task left uncompleted today automatically carries forward to tomorrow!

4. **Risk Management & Position Sizer**:
   - Fixed account capital setting.
   - Automated Maximum Risk calculation based on risk percentage.
   - Exact position sizing (shares/lots) and Risk-to-Reward ratio calculator.

5. **Profile Customization & Live Status**:
   - Upload and change your custom profile photo anytime using Android's Photo Picker.
   - Live real-time clock ticking every second and live market status.
